# gc-media

Alojamiento público de creatividades para las redes de **Garrido Consulting**.

Sirve las imágenes con URL pública y estable para que puedan publicarse
automáticamente en Instagram (la API de Meta exige una URL accesible desde
internet; no admite subida de ficheros locales).

## Estructura

```
ig/<slug-del-carrusel>/1.jpg, 2.jpg, ...
```

Las imágenes se numeran en el orden en que deben aparecer en el carrusel.

## URL pública

```
https://garridoconsulting.github.io/gc-media/ig/<slug>/1.jpg
```

## Reglas

- **Solo creatividades de marketing.** Este repositorio es PÚBLICO: nunca se
  sube nada de clientes, expedientes, documentación o datos personales.
- JPEG, máximo 8 MB, proporción entre 4:5 y 1,91:1 (requisito de Instagram).
